# Technical Scope

This file defines what the project is meant to prove and what it does not claim yet.

## In Scope

- Spring AI integration patterns.
- Prompt versioning and evaluation thinking.
- Model output validation and fallback design.
- Safety, cost, latency, and observability concerns.

## Out of Scope for Now

- Production model governance platform.
- Full RAG infrastructure at scale.
- Sensitive-data processing without clear controls.
- Claims that AI behavior is deterministic by default.

## Scope Statement

The project is scoped to prove AI engineering judgment. The next milestone is
one runnable lab with mocked model tests, evaluation examples, and fallback
behavior.
