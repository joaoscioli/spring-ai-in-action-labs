# Interview Route

Use this route to navigate the repository during a technical interview.

## Start Here

Open the README and explain that this is a Spring AI lab focused on backend
engineering around AI features.

## Show The Core Example

Start with `board-game-buddy`, then show prompt versioning, input guardrails,
API behavior, and WireMock tests.

## Discuss Engineering Judgment

Use the safety, evaluation, cost, latency, and rollout docs to explain that AI
features need the same engineering discipline as other production features.

## Close With The Next Step

Explain that a small evaluation dataset fixture would make prompt changes easier
to compare and review over time.
