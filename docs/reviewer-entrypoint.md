# Reviewer Entrypoint

Use this page when you have only a few minutes to evaluate the repository.

## First Three Files

- `README.md` for the project purpose and navigation.
- `docs/technical-scope.md` for what the project proves today.
- `docs/evaluation-observability.md` for AI quality and monitoring concerns.

## What To Look For

- AI features treated as software behavior that needs validation and fallback.
- Prompt versioning, evaluation, cost, latency, and safety considerations.
- Clear boundaries around where Spring AI helps and where governance is still needed.

## Strong Interview Signal

The repository is strongest when discussed as an AI engineering lab: it shows how
to integrate model behavior into backend systems with validation, evaluation, and
operational thinking.
