# Maintenance Plan

This plan keeps the project credible as an AI engineering portfolio.

## Monthly Review

- Review prompts, examples, and expected outcomes.
- Check cost, latency, safety, and fallback documentation.
- Add one deterministic test around the AI workflow boundary.

## Next Maintenance Targets

- Expand evaluation datasets with curated examples.
- Add provider fallback tests with mocked model responses.
- Keep prompt changes connected to review notes and expected behavior.

## Interview Signal

Maintained AI labs show that AI features are treated as engineered behavior, not
as one-off demos.
