# 30-Second Pitch

This repository is a Spring AI engineering lab for Java backend systems.

It demonstrates that I treat AI features as product and engineering work, not
as model demos. The project covers prompt versioning, input guardrails,
WireMock tests, evaluation, safety, cost, latency, observability, and
stakeholder value.

In an interview, I would use this repository to discuss responsible AI
integration, backend ownership around LLM behavior, and how to make AI features
reviewable.
