# Hiring Manager Summary

This repository supports the portfolio by showing modern AI engineering in Java.

## Why It Matters

It demonstrates that AI features can be treated as backend product features
with validation, tests, safety, evaluation, and observability.

## What To Notice

- Spring AI and Spring Boot implementation through `board-game-buddy`.
- Prompt versioning, input guardrails, and WireMock tests.
- Documentation for evaluation, cost, latency, safety, and rollout.
- Stakeholder-friendly framing of AI feature value.

## Interview Signal

This project is useful for discussing AI integration, product trade-offs,
testing around LLMs, and responsible backend ownership of emerging technology.
