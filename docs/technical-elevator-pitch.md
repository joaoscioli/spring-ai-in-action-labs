# Technical Elevator Pitch

This project is a Spring AI portfolio focused on integrating model-powered
features into backend systems with validation, fallback behavior, prompt
versioning, evaluation, safety, cost, latency, and observability.

## 30-Second Version

"I built this repository to show AI engineering as backend engineering. A model
call is an unreliable dependency, so the project focuses on contracts,
validation, evaluation, fallback paths, and operational visibility."
