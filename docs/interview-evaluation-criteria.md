# Interview Evaluation Criteria

Use these criteria to evaluate the project during a technical interview.

## Baseline Signal

- Explains Spring AI integration concepts.
- Understands prompts, model calls, and backend endpoints.
- Navigates the AI engineering documentation.

## Strong Signal

- Discusses validation, fallback behavior, prompt versioning, and evaluation.
- Connects model output to cost, latency, safety, and observability.
- Explains why AI behavior needs explicit contracts.

## Senior Signal

- Treats model calls as unreliable external dependencies.
- Designs for monitoring, quality checks, and safe failure modes.
- Balances product usefulness with governance, data boundaries, and operational risk.
