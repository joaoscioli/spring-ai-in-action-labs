# Key Talking Points

Use these points to keep the interview conversation focused.

## Lead With

- AI features should be treated as backend product features.
- Prompt versioning, guardrails, evaluation, and observability matter.
- WireMock tests keep model integration paths reviewable.

## Go Deeper On

- What should not be sent to an LLM.
- How cost and latency influence product design.
- Why evaluation is needed when prompts change.

## Avoid Overclaiming

- Do not present prompt engineering as the whole solution.
- Explain the backend controls around the model call.
