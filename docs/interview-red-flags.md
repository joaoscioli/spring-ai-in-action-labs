# Interview Red Flags

Use this file to avoid weak signals during a technical interview.

## Avoid Saying

- "The feature is just a call to the model."
- "Prompt quality is subjective."
- "AI tests are not reliable, so we do not test them."
- "We can send the full user context to improve results."

## Say Instead

- The engineering work is around validation, evaluation, fallback, and safety.
- Prompts are behavior and should be reviewed with examples.
- Deterministic boundaries can be tested with mocked model responses.
- Data sent to models must be minimized, justified, and protected.
