# Production Readiness Matrix

This matrix separates AI demos from production AI feature readiness.

| Capability | Current State | Production Expectation |
| --- | --- | --- |
| Prompt behavior | Prompt versioning is documented. | Reviewed prompt changes with evaluation examples. |
| Model output | Validation and fallback guidance exists. | Strict contracts, guardrails, and safe degradation. |
| Evaluation | Templates and runbooks are available. | Repeatable datasets and quality thresholds. |
| Operations | Cost, latency, and safety are mapped. | Metrics, limits, alerts, and incident procedures. |

## Review Note

The project becomes interesting to senior reviewers when AI is surrounded by
testability, observability, cost control, and risk management.
