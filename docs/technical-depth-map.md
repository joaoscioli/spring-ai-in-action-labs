# Technical Depth Map

This map connects the repository to the skills a technical reviewer may look for.

## AI Feature Engineering

- AI behavior is treated as application behavior.
- Prompt versioning makes changes reviewable.
- Input guardrails reduce unsafe or wasteful model calls.

## Testing And Evaluation

- WireMock tests keep model integration paths deterministic.
- Evaluation docs explain how prompt changes should be compared.
- Safety and refusal behavior are part of the expected design.

## Product And Operations

- Cost, latency, observability, and stakeholder demos are documented.
- The project connects AI choices to backend ownership, not only experimentation.

## Interview Use

Start with `board-game-buddy`, then explain how validation, evaluation, and
fallback behavior surround the model call.
