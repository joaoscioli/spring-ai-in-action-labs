# Reviewer FAQ

## What should I review first?

Start with the README, AI engineering positioning, prompt versioning,
evaluation runbook, and safety checklist.

## What is the main technical signal?

The project treats AI integration as backend engineering work around prompts,
validation, evaluation, cost, latency, safety, and fallback behavior.

## What is intentionally unfinished?

A larger evaluation dataset and provider fallback implementation can still be
added as the labs become more executable.

## What should we discuss in an interview?

Discuss AI boundaries, prompt review, deterministic testing, model output
validation, privacy, cost controls, and production rollout risk.
