# Live Review Script

Use this script when sharing the repository during an interview.

## Opening

This repository presents Spring AI as an engineering discipline: prompts, tools, retrieval, evaluation, cost, and safety.

## Walkthrough order

1. Start with `README.md` to frame the use cases.
2. Explain model selection and prompt versioning.
3. Show tool calling or RAG documentation.
4. Discuss evaluation datasets and observability.
5. Close with cost, latency, and rollout controls.

## Strong signal

The repository shows how to make AI features reviewable, measurable, and safer to operate.
