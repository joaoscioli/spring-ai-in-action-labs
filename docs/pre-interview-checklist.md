# Pre-Interview Checklist

Use this checklist before presenting the repository.

## Review Before The Call

- Open the fast review path and interview case study.
- Prepare one board-game-buddy request flow.
- Know where prompt versioning, guardrails, and WireMock tests appear.
- Be ready to explain cost, latency, safety, and evaluation trade-offs.

## Be Ready To Show

- `SpringAiBoardGameService`
- WireMock integration tests
- prompt versioning docs
- evaluation runbook and safety checklist

## Strong Close

Explain that the value is not calling an LLM, but making AI behavior reviewable.
